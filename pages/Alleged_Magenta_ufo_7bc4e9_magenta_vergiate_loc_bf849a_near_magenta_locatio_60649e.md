## Introduction

“Near Magenta” is the most persistent geographical description attached to the alleged 1933 Italian UFO recovery, but it is much less precise than the familiar name “Magenta crash” suggests. The public evidence supports, at most, an association with the **Magenta area of Lombardy, west of Milan**. It does not establish an authenticated impact coordinate, named farm, road, hamlet, cadastral parcel or identifiable recovery field.

That distinction is central to the Magenta-versus-Vergiate question. Sources closest to the modern development of the story generally assign different roles to the two places: the unknown object was allegedly recovered **near Magenta**, while the recovered material was supposedly transported to an aviation facility at **Vergiate**. The Centro Ufologico Nazionale (CUN), associated with researcher Roberto [Pinotti]({{ 'pinotti/' | relative_url }}), still uses the deliberately approximate wording “in proximity to Magenta”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.centroufologiconazionale.eu/rivelazioni-di-david-grusch-sui-file-fascisti-comunicato-stampa-cun/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: centroufologiconazionale.eu">[CENTRO UFOLOGICO NAZIONALE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">centroufologiconazionale.eu</span><span class="citation-popover-title">CENTRO UFOLOGICO NAZIONALERivelazioni di David Grusch sui file fascisti</span><span class="citation-popover-snippet">Comunicato Stampa CUN - CENTRO UFOLOGICO NAZIONALEJune 13, 2023...</span><span class="citation-popover-meta">Published: June 13, 2023</span></span></span>

The result is an unusual evidential situation. Magenta is reasonably secure as the **geographical label of the claim**, but the actual site underneath that label remains unidentified.

## Where the “near Magenta” wording comes from

The modern Magenta case rests principally on [documents]({{ 'documents/' | relative_url }}) that surfaced many decades after 1933 rather than on a continuously documented local incident. According to a preliminary review by the New Paradigm Institute, Italian researchers began investigating the story in the 1990s after Roberto Pinotti received batches of purported Fascist-era material. The first batch, reportedly received in January 1996, included letters on Italian Senate stationery and three purported telegrams from the Milan Telegraphic Office, all dated [13 June]({{ '13-june/' | relative_url }}) 1933. Later batches contained material concerning unidentified aircraft and the alleged secret research organisation usually called the RS/33 Cabinet.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://newparadigminstitute.org/learn/library/case-study-magenta-italy-1933/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: newparadigminstitute.org">[New Paradigm Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">newparadigminstitute.org</span><span class="citation-popover-title">case study magenta italy 1933</span><span class="citation-popover-snippet">New Paradigm InstituteCase Study Magenta Italy 1933 – New Paradigm Institute...</span></span></span>

That [provenance]({{ 'provenance/' | relative_url }}) is crucial to understanding the location claim. These papers did **not** emerge from an identified government archive with a catalogue reference and documented chain of custody. Critical researcher Pepijn van Erp notes that the material came through an [anonymous source]({{ 'anonymous-source/' | relative_url }}) and argues that the supposed official papers lack the archival provenance normally required to establish their authenticity. He also points out that although Pinotti has said forensic examination found paper and ink compatible with the claimed period, the underlying forensic report has not been made publicly available for independent scrutiny.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.pepijnvanerp.nl/2023/06/mussolinis-ufo-cabinet-rs-33/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pepijnvanerp.nl">[Pepijn van Erp]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pepijnvanerp.nl</span><span class="citation-popover-title">Pepijn van Erp Mussolini’s UFO – Cabinet RS/33 – Pepijn van Erp</span><span class="citation-popover-snippet">Pepijn van ErpMussolini’s UFO – Cabinet RS/33 – Pepijn van ErpJune 6, 2023...</span><span class="citation-popover-meta">Published: June 6, 2023</span></span></span>

Even the New Paradigm Institute's sympathetic preliminary review acknowledges essentially the same evidential limitation: forensic testing has been claimed, but the full laboratory reports have not been published and independent verification has not been supplied. It also reports that corroborating archival documentation establishing the existence and activities of RS/33 has not been found.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://newparadigminstitute.org/learn/library/case-study-magenta-italy-1933/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: newparadigminstitute.org">[New Paradigm Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">newparadigminstitute.org</span><span class="citation-popover-title">case study magenta italy 1933</span><span class="citation-popover-snippet">New Paradigm InstituteCase Study Magenta Italy 1933 – New Paradigm Institute...</span></span></span>

That means “near Magenta” cannot presently be treated like a location extracted from an authenticated contemporary accident report. It is a geographical assertion transmitted through a disputed documentary tradition.

CUN's own 2023 description is revealing. Its press release says that an unidentified object was recovered in Lombardy in 1933 “in proximity to Magenta”. The organisation does not identify a street, village, property or coordinate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.centroufologiconazionale.eu/rivelazioni-di-david-grusch-sui-file-fascisti-comunicato-stampa-cun/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: centroufologiconazionale.eu">[CENTRO UFOLOGICO NAZIONALE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">centroufologiconazionale.eu</span><span class="citation-popover-title">CENTRO UFOLOGICO NAZIONALERivelazioni di David Grusch sui file fascisti</span><span class="citation-popover-snippet">Comunicato Stampa CUN - CENTRO UFOLOGICO NAZIONALEJune 13, 2023...</span><span class="citation-popover-meta">Published: June 13, 2023</span></span></span>

A major Italian newspaper uses similarly broad language. In a 2023 retrospective on Milan-area UFO stories, *Corriere della Sera* described the supposed 1933 object as having landed “near Magenta”. Whatever one makes of the underlying claim, the continued use of that wording demonstrates that the case has not acquired a generally accepted, more exact location through subsequent research.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://milano.corriere.it/notizie/cronaca/23_agosto_20/ufo-a-milano-agosto-record-di-avvistamenti-dal-primo-atterrato-a-magenta-a-quello-segnalato-dal-papa-di-martin-mistere-8b49f71f-5aee-48d6-9c18-8cf3ad803xlk_amp.shtml" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: milano.corriere.it">[Corriere Milano]</a><span class="citation-popover" role="note"><span class="citation-popover-source">milano.corriere.it</span><span class="citation-popover-snippet">Corriere MilanoUfo a Milano, agosto record di avvistamenti: dal primo atterrato a Magenta a quello segnalato dal papà di «Martin Mystére»...</span></span></span>

## What the surviving location claims actually establish

The geographical claim can usefully be separated into different levels of precision.

At its strongest defensible level, it identifies **Magenta as the reference locality**. The New Paradigm Institute places the alleged event near Magenta, approximately 25 kilometres west of Milan. CUN likewise places the recovery in proximity to Magenta. Critical treatments of the story, including Van Erp's examination of the RS/33 material, agree that this is where Pinotti's narrative places the supposed 1933 recovery, even while disputing whether the underlying documents are genuine.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://newparadigminstitute.org/learn/library/case-study-magenta-italy-1933/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: newparadigminstitute.org">[newparadigminstitute.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">newparadigminstitute.org</span><span class="citation-popover-title">case study magenta italy 1933</span><span class="citation-popover-snippet">New Paradigm InstituteCase Study Magenta Italy 1933 – New Paradigm Institute...</span></span></span>

That convergence matters. Supporters and critics disagree profoundly about the credibility of the event, but they can still identify what the claim actually says: **the alleged recovery was associated with the vicinity of Magenta**.

The next level of precision, however, is missing. No source with demonstrated archival provenance has been produced that identifies the supposed impact location in a way that could be independently reconstructed. There is no publicly authenticated contemporary recovery map. No securely sourced police or military report provides coordinates. No named landowner has been tied through contemporary documentation to a particular property where the object was allegedly found. No verified 1933 eyewitness account supplies directions capable of locating the spot.

The New Paradigm Institute's reconstruction illustrates the gap particularly clearly. It can summarise the event as a disc- or bell-shaped object that supposedly crashed or was forced to land “near Magenta”, yet its detailed inventory of the alleged documents does not yield a crash coordinate. ## “Near Magenta” does not necessarily mean inside Magenta

There is another geographical subtlety. A statement that something happened “near Magenta” does not necessarily place it within the municipality's administrative boundary.

Place-names routinely function as reference points. A rural event may be described using the nearest recognisable town even when the actual location belongs to another municipality. Without a contemporary source specifying jurisdiction, therefore, it would be unsafe to convert “near Magenta” into “inside the Comune di Magenta”.

That distinction matters especially in a case where the rural setting is central to later descriptions. Magenta's municipal sources show that the surrounding environment belongs to a wider Ticino and Naviglio landscape rather than an isolated urban island. The municipality itself emphasises its agricultural and natural surroundings, including springs, woodland and cultivated land.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://comune.magenta.mi.it/vivere-il-comune/la-citta-di-magenta/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: comune.magenta.mi.it">[Comune di Magenta]</a><span class="citation-popover" role="note"><span class="citation-popover-source">comune.magenta.mi.it</span><span class="citation-popover-title">Comune di Magenta La Città di Magenta – Comune di Magenta</span><span class="citation-popover-snippet">Comune di MagentaLa Città di Magenta – Comune di MagentaJanuary 9, 2024...</span><span class="citation-popover-meta">Published: January 9, 2024</span></span></span>

The same applies to pins placed on the outskirts of the town. Unless the mapmaker can identify the historical source from which the coordinates were derived, apparent precision is merely graphical. ## Why the missing coordinate matters

For an ordinary retelling, the difference between “Magenta” and “somewhere near Magenta” can seem trivial. For historical verification, it is enormous.

A genuine location would create testable lines of inquiry. Researchers could identify who owned the land in 1933, determine which police or administrative authority covered it, search the relevant municipal and provincial records, inspect historical maps and cadastral documents, look for contemporary correspondence, and investigate whether later land use preserved or destroyed potential physical evidence.

A documented location could also make contemporary press searches more effective. An unexplained explosion, aircraft accident, fire, military cordon or unusual police activity might have been reported under the name of a smaller village rather than Magenta itself. Without knowing the locality, archival searches organised around “Magenta” risk missing records filed under neighbouring jurisdictions.

Conversely, a real coordinate would allow negative evidence to become more meaningful. If researchers knew precisely which farm was involved and could show that its owners' records, local police files and contemporary [newspapers]({{ 'newspapers/' | relative_url }}) contained no sign of the extraordinary recovery later claimed, that would materially affect the case. At present, the broadness of “near Magenta” makes both confirmation and falsification harder.

The absence of an identifiable site therefore is not a cosmetic omission. It limits the historical testability of the story.

## What would genuinely narrow the site

A meaningful advance would require evidence that connects the general Magenta claim to a specific piece of terrain independently of later storytelling.

The strongest possibilities would include an authenticated 1933 document naming a locality or property; a contemporary military or police report containing a route or map reference; cadastral information tied to a named landowner; contemporary correspondence identifying the recovery ground; or multiple independently sourced witness accounts converging on the same location.

A newly produced map would not be enough merely because it looks old. Its provenance would matter: where it was archived, who created it, when it entered the collection and whether its markings can be shown to be contemporary with the alleged event.

The same standard applies to physical investigation. Metal fragments, unusual soil or a ground anomaly found somewhere around Magenta would have little probative value unless an independent documentary trail first connected that location to the alleged 1933 event.     }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
